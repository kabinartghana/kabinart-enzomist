# Enzomist

Custom ERPNext app for Enzomist — the commercial aroma diffuser brand under Kabinart Ghana Ltd.

Covers:
- Aroma Device catalogue (24 models with k-values)
- Device Placements at commercial client sites
- Refill logging with automatic stock deduction
- Refill prediction engine (proprietary formula)
- CRM pipeline for commercial, retail and wholesale channels
- Consignment warehouse management
- Oil manufacturing BOMs

Built on Frappe Framework v15/v16.
